# Booking page appearance

Open Settings, My Account, then Booking appearance. The editor can suggest colors from a public website and includes a teal-and-cream preset. Adjust the brand name, website link, HTTPS logo URL, colors, heading font and corners. Preview desktop or mobile and save to publish. The design applies to supported standalone guest booking pages.

For instance-level labels, set `NEXT_PUBLIC_APP_NAME` and `NEXT_PUBLIC_WEBSITE_URL` before building.
