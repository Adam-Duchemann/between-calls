# Connect an assistant

In Settings, open AI assistants to get the server URL for your installation. It has the form `https://booking.example.com/api/mcp`. Connect it using a client that supports remote MCP and OAuth. The connection permits only the scopes the host grants. Read requests can access booking and schedule data, which may include attendee information.

Changes from an assistant create proposals. Open the returned review link while signed in as the host, check the details and confirm the proposal in the app. Revoke unwanted clients from the AI assistants settings.
